# 🌱 Plantagotchi

A smart desktop plant care assistant built with C# and WPF.

Plantagotchi helps users take care of their plants through an interactive desktop application with AI-powered features, plant management, reminders, and a modern user interface.

---

## ✨ Features

- 🌿 Plant management system
- 💧 Watering reminders
- 🤖 AI-assisted plant care tips
- 🖥️ Modern WPF desktop UI
- 📊 Plant status tracking
- 🧠 MVVM architecture
- 📁 Local data handling

---

## 🛠️ Technologies Used

- C#
- WPF
- .NET
- MVVM Pattern
- XAML

## 🚀 Getting Started
### Requirements
- Visual Studio 2022
- .NET SDK
- Windows OS
### Run the project
- Clone the repository
- ```git clone https://github.com/bazskos/Plantagotchi.git```
- Open the solution in Visual Studio
- Restore NuGet packages
- Run the application

---

## 🔑 Environment Variables

Create a `.env` file in the root directory of the project and add the following variables:

```env
OPENAI_API_KEY=your_api_key_here
```

The `.env` file is excluded from version control for security reasons.
